How to Spot a Fake Lossless File

Scammers and unverified file sharing sites frequently convert 128kbps or 192kbps MP3 files into .flac format to fool audio collectors. While the file extension and container say FLAC, the audio itself is permanently degraded.

  • 16 kHz cutoff: Indicates an old 128 kbps MP3 transcode.
  • 18.5 kHz cutoff: Common in 192 kbps to 256 kbps MP3 or AAC encodes.
  • 20 kHz cutoff: High-quality 320 kbps MP3.
  • Smooth continuation beyond 21 kHz: Authentic lossless CD-quality (16-bit / 44.1 kHz) or Hi-Res audio.
